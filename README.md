I did not create a separate jupyter notebook since I refactored the code quite well and cleanly. Each part is in its own folder, 
and the readme file of the project tells what commands to run on each part/folder. You can just copy paste each command and you 
can run the commands and scripts yourself on your own local computer. Run the parts/folders individually and one at a time.

Requirements and running the project

The project was developed and tested using Python 3.14 on Windows.

Use the first commands which are: python -m part_1.article_extracting and so on and so forth. These commands should work and that's all you should need to do. 

Run each part individually, one at a time, using the commands listed below.

Note: The commands are written for Windows PowerShell. Other operating systems may require slightly different commands.

Install requirements: python -m pip install -r requirements.txt
